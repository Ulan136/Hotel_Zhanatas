# MEDINA — учёт гостиницы (Hotel Zhanatas)

Веб-приложение для вахтового общежития: комнаты, гости, финансы (доходы/расходы),
смены персонала и отчёты. **Next.js + Neon (Postgres) + Vercel.**

- **Фронтенд + API:** Next.js (App Router), деплой на Vercel
- **База данных:** Neon Postgres
- **API:** один эндпоинт `POST /api/rpc` (`lib/client.js` → `api(action, params)`)

Страницы:

| Адрес | Кто | Назначение |
|-------|-----|-----------|
| `/` | все | Выбор роли |
| `/admin` | админ / ресепшн | Комнаты, финансы, смены, отчёты, настройки |
| `/guest` | гость | Регистрация по QR (3 шага) |
| `/guard` | охрана | Приход/уход по QR, часы считаются автоматически |
| `/report` | заказчик | Отчёт о проживании (только чтение) |

Старая версия (Google Apps Script) сохранена в папке `legacy/`.

---

## Что улучшено при переезде

- **Пароли хешируются** (bcrypt) — раньше шли открытым текстом в URL.
- **Надёжность данных:** схема Postgres с ограничениями. Главное —
  уникальный индекс `one_active_stay_per_room`: **нельзя заселить в занятую комнату**
  даже при одновременных запросах.
- **Тёмная тема** и аккуратная мобильная вёрстка (адаптируется под систему).

## Шаг 1. База данных Neon

1. Зайдите на [neon.tech](https://neon.tech) → создайте проект (регион — ближе к Казахстану, напр. `eu-central-1`).
2. В проекте откройте **Connection Details** → скопируйте **Connection string**
   (вида `postgresql://...neon.tech/neondb?sslmode=require`).
3. Разверните схему одним из способов:
   - **Просто:** откройте в Neon **SQL Editor**, вставьте содержимое `scripts/schema.sql`, нажмите Run.
   - **Через скрипт:** создайте файл `.env.local` (см. `.env.example`), вставьте `DATABASE_URL`, затем:
     ```bash
     npm install
     npm run db:setup
     ```

## Шаг 2. Запуск локально

```bash
npm install
# создайте .env.local со строкой DATABASE_URL (см. .env.example)
npm run dev
```
Откройте http://localhost:3000 — первая регистрация создаёт администратора.

## Шаг 3. Деплой на Vercel

1. [vercel.com](https://vercel.com) → **Add New… → Project** → импортируйте GitHub-репозиторий `Ulan136/Hotel_Zhanatas`.
2. Framework Preset определится как **Next.js** автоматически.
3. **Settings → Environment Variables** → добавьте:
   - `DATABASE_URL` = строка подключения Neon (для окружений Production, Preview, Development).
4. **Deploy**. Дальше каждый `git push` в `main` деплоит автоматически.

> Совет: в Neon включите интеграцию с Vercel (Neon → Integrations → Vercel),
> тогда `DATABASE_URL` пропишется в проект Vercel автоматически.

## Первый вход и настройка

1. Откройте `/admin` → зарегистрируйте администратора.
2. **⚙ Настройки:**
   - **Гости** — кто заселяется;
   - **Работники** — персонал (должность «Охрана» → появляется на `/guard`);
   - **Категории** — статьи доходов/расходов (с подкатегориями);
   - **Пользователи** — доступы (роли: админ / ресепшн / заказчик).
3. Для QR печатайте прямые ссылки: `/guest`, `/guard`, `/report`.

## Роли

- **admin** — полный доступ.
- **reception** — всё, кроме управления пользователями.
- **factory (заказчик)** — только `/report`.

## Структура

```
app/
  page.js            — лендинг
  admin/page.js      — кабинет персонала
  guest/page.js      — регистрация гостя
  guard/page.js      — охрана
  report/page.js     — отчёт заказчика
  api/rpc/route.js   — весь бэкенд (действия + SQL)
lib/
  db.js              — клиент Neon
  client.js          — api() + сессия
  ui.js              — форматирование
components/kit.js    — шапка, модалка, спиннер
scripts/
  schema.sql         — схема БД
  setup-db.mjs       — разворачивание схемы
legacy/              — прежняя версия (Apps Script)
```
